# Tagmark 4.42

제공된 Tagmark 4.41 HTML을 기반으로 입력·표시 구성 합의안을 통합한 버전입니다.

## 실행

압축을 풀고 `index.html`을 엽니다. 별도 설치나 빌드가 필요 없습니다.
기존 파일을 교체할 때는 먼저 4.41의 DB 관리에서 전체 DB를 내보내 두세요.
기존 데이터가 자동으로 나타나지 않으면 4.42의 DB 관리에서 해당 전체 DB 백업을 가져오면 됩니다.
4.41의 데이터베이스 이름과 Format 1 형식을 유지했습니다.

## 반영 사항

- 정보 생성·이름·유형·입력 방식 관리를 입력 구성으로 통합. 정보 항목 탭과 입력 세부 설정 제거.
- 입력에서 새 정보를 생성하면 연결된 표시 항목 하나 자동 생성.
- 초기값 설정과 자동 적용 제거. 직접 입력 방식에만 입력 힌트 표시.
- 시각 유형 추가. 날짜·시각·날짜+시간과 시간 길이 구분.
- 예/아니오 및 단일 선택값의 순환 버튼. 미입력·아니오를 구분하고 지우기 지원.
- 선택지 목록 편집: 추가·이름 변경·삭제·드래그 순서 변경, 빈 이름·중복 이름 검사.
- 선택지의 고유 식별자를 유지하고 이름 변경 시 기존 저장값 갱신. 삭제 시 대체 또는 비우기 선택.
- 설정의 선택 가능한 옵션이 하나이면 선택 조작 제거·자동 지정. 실제 데이터의 유일한 선택값은 직접 선택.
- 입력과 표시의 독립적인 한 단계 폴더형 묶음. 전체 이동·내부 항목 이동·묶음 밖으로 꺼내기·묶음 해제.
- 표시 유형을 정보 유형에 맞게 제한. 메모는 작은 연한 글씨, 레코드는 레코드 카드.
- 표시 숨김·복원은 정보와 저장값 유지. 정보 항목 삭제는 별도 확인 후 연결된 구성과 값까지 삭제.
- 고급 설정은 조건별 항목만 표시. 긴 선택지·분류·조회 범위는 별도 편집창에서 설정.
- 태그·카테고리 배분 규칙·우선순위·미분류 수신 항목, 레코드 조회 범위·복수 연결·생성 허용 유지.
- 색상 설정은 별도 유지. 구성 변경 및 정보 정의 변경은 구성 저장 시 함께 적용, 취소 시 폐기.

## 확인한 동작

Chromium에서 4.41 데이터의 로드·저장 및 북마크·레코드 값 유지, 정보 생성·취소, 시각 입력, 예/아니오 순환과 필수 검사, 표시 숨김·복원, 선택지 이름 변경·삭제 대체, 복수 입력과 데이터 손실 변환 차단, 레코드 카드 생성·원본 연결·저장, 묶음 이동·해제 및 실제 마우스 드래그를 확인했습니다. PC·모바일 화면과 데이터 참조 유효성도 점검했습니다.

선택지의 단일/복수 전환에서 기존 복수 값이 두 개 이상이면 단일 전환을 막습니다. 저장값이 있는 정보의 유형 변경도 기존 보호 동작을 유지합니다.
