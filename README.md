# Tagmark v4.04

v4.03을 기준으로 과거 버전에서 유용했던 편의 기능을 v4 데이터 모델에 맞게 1차 복원한 버전입니다.

## 추가된 편의 기능
- Bookmark / Record 편집 모달에서 복제
- 선택 모드에서 선택 해제
- Bookmark 편집에서 Record 관계(등장인물) 복사
- 선택한 여러 Bookmark에 복사한 등장인물 Record 관계 붙여넣기
- Page Settings에서 Tab 복제
- Category 편집에서 바로 하위 Category 생성

## 설계 원칙
- 과거 버전의 저장 구조를 되살리지 않고 v4 Canonical DB / Record Relation 구조를 사용합니다.
- 등장인물 복사/붙여넣기는 Record 자체를 중복 생성하지 않고 기존 Record 관계를 재사용합니다.
- 기존 v4.03 기능 및 모바일 대응을 유지합니다.

## 검증
- JavaScript 구문 검사(Node --check): 통과
- 파일/패키지 구조 확인: 완료
- 실제 브라우저 클릭 통합 테스트: 현재 채팅 실행 환경에서는 수행하지 못함

## 다음 단계 후보
과거 버전 소스를 계속 대조해 검색 범위, 빠른 태그/프로필 조작, 카테고리/태그 관리 편의, 카드 액션 등 누락된 UX를 v4 구조 위에 순차 복원합니다. 이후 구형 UI의 시각/조작 체계를 v4 엔진 위에 이식합니다.
