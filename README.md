# v4.50

압축을 풀고 index.html을 브라우저에서 엽니다. v4.49를 기준으로 탭별 툴바와 편집 동작을 개편했습니다.

## 작업 위치와 고정 툴바

검색·입력 영역과 일반/선택 툴바를 상단에 고정하고 카드·태그·카테고리 내용만 스크롤합니다. 변경 후 화면을 다시 그릴 때 보던 항목과 화면 내 위치를 복원합니다. 보던 항목이 삭제되면 인접 항목을 사용합니다. 탭을 오갈 때도 목록 위치를 보존합니다. 새 검색이나 정렬·필터 적용은 결과 처음부터 확인합니다.

모달도 저장 후 스크롤과 펼친 설정을 유지합니다. 선택 모드에서 개수와 목록 밖 선택 개수는 상태줄에 표시해 툴바 높이 변화를 줄였습니다.

## 일반 툴바

| 탭 | 검색·입력 | 왼쪽 | 오른쪽 |
|---|---|---|---|
| 북마크 | 검색창·필터 | 북마크+·선택 | 보기·구성·더보기 |
| 레코드 | 검색창·필터 | 레코드+·선택 | 보기·구성·더보기 |
| 태그 | 검색·추가 통합 입력칸·추가 대상 헤드·태그+ | 선택 | 필터·태그 헤드 관리·탭 설정 |
| 카테고리 | 검색창·필터 | 카테고리+·선택 | 보기·탭 설정 |

북마크·레코드의 구성에는 입력/표시/색상 구성을 두고 탭 설정은 더보기로 옮겼습니다. 북마크의 폴더 관리도 더보기에 있습니다. 레코드의 정렬과 정보 기준 그룹은 보기에서 선택합니다.

태그는 입력하면 검색하고 태그+를 누를 때만 생성합니다. Enter로 생성하지 않습니다. 추가 후 입력값과 대상 헤드를 유지하며 중복 생성을 검사합니다. 등록할 헤드와 표시할 헤드는 독립적입니다. 태그 필터에 사용 여부·정렬·보기 방식·색상 방식·표시할 헤드를 모았습니다. 태그 헤드 추가는 관리 화면 안에서 합니다.

카테고리의 보기에는 정렬·트리/목록·모두 펼치기/접기를 둡니다. 모두 펼치기/접기는 트리에서 사용합니다.

## 선택 전용 툴바

일반 툴바를 같은 위치에서 대체합니다. 모든 탭의 기본 순서는 현재 목록 전체 선택 → 수정/일괄 수정 → 더보기 → 선택 해제입니다. 카테고리는 더보기를 두지 않습니다.

- 1개 선택: 수정. 복수 선택: 일괄 수정. 선택 0개: 수정 비활성화.
- 현재 목록 전체 선택: 현재 검색·필터 결과 전체를 선택합니다.
- 선택 해제: 선택을 모두 해제하고 일반 툴바로 돌아갑니다.
- 북마크의 더보기: 폴더 이동 → 레코드 붙여넣기 → ID로 검색.
- 레코드·태그의 더보기: ID로 검색.
- ID 검색은 현재 페이지·탭 안에서 검색하며 찾은 항목을 선택에 추가합니다.

삭제는 수정/일괄 수정 모달 안에서 사용합니다. 레코드 수정에는 태그·카테고리 추가 접근도 있습니다. 태그의 일괄 수정은 헤드/색상 변경, 카테고리는 상위 카테고리 변경을 지원합니다. 카테고리는 자신의 하위로 이동하는 순환 관계를 차단합니다.

## 카드와 모달

북마크의 열기 버튼을 제거하고 제목 링크를 사용합니다. 북마크·레코드 카드 하단은 왼쪽 수정, 오른쪽 복제·삭제 순서입니다. 북마크 편집 하단에는 복제·삭제를 두지 않습니다. 레코드의 삭제 등 추가 작업은 편집 본문에 배치합니다.

모달 하단은 왼쪽의 작은 보조 취소와 오른쪽 저장을 분리했습니다. 저장/적용해도 창을 유지하며 저장 상태를 표시합니다. 신규 항목은 첫 저장 후 같은 항목의 수정 상태로 전환해 다시 저장할 때 중복 생성하지 않습니다. 일괄 수정은 변경 미리보기와 제한 검사를 유지합니다.

배경은 모달 바깥에서 누르고 뗀 경우에만 닫힙니다. 모달 안에서 누른 뒤 바깥에서 놓는 드래그는 닫기로 처리하지 않습니다. 한 번의 배경 클릭은 가장 위 편집 하나만 닫고 뒤쪽으로 전달되지 않습니다. 닫기·취소·배경 클릭·Escape는 마지막 저장 이후의 미저장 변경을 버립니다. 이미 저장한 내용을 되돌리지는 않습니다.

입력/표시 구성의 하위 편집에서 적용한 변경은 부모의 임시 구성에 반영됩니다. 상위 구성에서 저장해야 실제 데이터에 확정됩니다. 하위 적용 후에도 창을 유지하고, 뒤로 돌아오면 부모의 작성값을 유지합니다. 태그 헤드 관리는 이름·색상·순서와 추가/삭제 정책을 임시 편집한 뒤 저장합니다.

공통 검색에서 새 태그·카테고리를 생성한 경우 분류 목록에 생성하는 작업과 북마크·레코드의 선택값을 저장하는 작업은 별개입니다. 새 분류 생성은 명시적 생성 동작으로 저장하고, 그 값을 현재 항목에 넣는 것은 상위 편집에서 저장합니다.

## 검증

브라우저에서 다음을 확인했습니다.

- 긴 목록의 재렌더링 후 위치 유지와 상단 고정.
- 수정 저장 후 모달/스크롤 유지, 저장 후 추가 변경 취소, 신규 생성 재저장 시 중복 방지.
- 배경 한 번으로 하위 편집 한 단계만 닫기, 부모 취소 시 임시 구성 미반영.
- 네 탭의 툴바 순서·단일/일괄 수정 연결·삭제 위치와 모바일 너비.
- 태그 검색/추가 통합·Enter 생성 방지·중복 검사·일반 클릭 수정.
- 필터의 포함/제외 임시 편집과 취소/저장.
- 태그 헤드 드래그 임시 순서와 저장, 카테고리 순환 이동 차단.
- 기존 일괄 수정의 0·아니오·슬라이더·태그 추가/제거·레코드 연결, 제한 검사·취소.
- 묶음 자동 배분·수신 항목 제한·수동 수신 지정·기존 위치에서 제거.
- 슬라이더 자동 모드의 10개 이름과 가운데 값 선택, 레코드 접기/펼치기.
- v4.49 데이터 보존과 저장 데이터의 재시작 후 보존.
