# v4.47

압축을 풀고 index.html을 브라우저에서 열면 됩니다. 기존 데이터 형식을 유지합니다.

## 변경 사항

- 북마크 툴바의 ‘선택’ 버튼을 선택 전용 툴바에 연결했습니다. 0개 선택 상태에서도 툴바를 열고 ID로 수정 대상을 찾을 수 있습니다.
- 검색어를 입력할 때만 관련 후보를 드롭다운으로 표시합니다. 앱의 색상과 형태를 맞췄으며 방향키·Enter·Escape를 지원합니다.
- 북마크 안의 레코드는 제목을 한 번 표시하고 펼치면 제목을 제외한 하위 정보를 보여줍니다. 제목 색상 설정도 유지합니다.
- 일괄 수정에서 대상 ID와 입력값 ID를 확인하고, 입력 구성에 지정한 입력기를 재사용합니다. 변경 미리보기와 제한 검사를 거쳐 적용합니다. 입력하지 않으면 변경하지 않으며, 값을 지우려면 ‘비우기’를 사용합니다.
- 태그·카테고리 검색기를 해당 항목 아래에 배치했습니다. 입력 묶음에 개별 입력·공통 검색 및 자동 배분·입력기 전환 방식을 추가했습니다.

## 입력 묶음 사용

입력 구성에서 묶음의 입력 방식을 설정합니다.

- **개별 입력**: 각 항목의 입력기를 사용합니다.
- **공통 검색 및 자동 배분**: 공통 검색기를 사용하는 태그·카테고리 항목으로 구성된 묶음에 사용합니다. 각 항목의 ‘받을 분류’와 우선순위를 설정하고 묶음 검색 범위를 지정합니다. 선택한 값은 맞는 태그 헤드 또는 가까운 상위 카테고리를 기준으로 배분됩니다. 같은 범위가 겹치면 우선순위, 구성 순서로 결정합니다. 받을 항목을 결정할 수 없으면 항목을 직접 선택합니다.
- **입력기 전환**: 사용할 항목을 선택하면 그 입력기가 나타납니다. 다른 입력기로 전환해도 이미 입력한 값은 유지됩니다.

묶음 생성·해제나 구성 변경만으로 기존 저장값을 재배분하지 않습니다. 공통 검색에서 추가한 값은 해당 묶음 안에서 중복되지 않도록 정리합니다.

## 확인

브라우저에서 선택 툴바, 검색 후보 클릭 및 키보드 선택, 묶음 자동 배분과 범위 제한, 입력기 전환 시 값 유지, 레코드 제목 중복 제거를 확인했습니다. 일괄 수정은 숫자 0·아니오·슬라이더·태그 추가/제거·레코드 연결의 저장, 제한 오류 차단, 취소 시 값 유지를 확인했습니다. 모바일 너비와 v4.46 데이터 보존 검사도 통과했습니다.
