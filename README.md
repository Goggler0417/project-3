# v4.38

index.html을 브라우저에서 열어 사용합니다. 기존 데이터를 먼저 JSON으로 내보낸 뒤 새 파일을 여세요. 파일 주소가 달라져 기존 데이터가 안 보이면 JSON을 가져오세요.

4.36의 입력 구성·표시 구성·색상 설정·정보 항목 관리 분리를 유지했습니다.

- 입력 구성: 정보 유형과 입력 방식을 기본 화면에 표시합니다. 이름, 안내 문구, 초기값, 필수 여부, 배치, Record 범위와 분류 규칙은 고급 설정입니다. 정보 유형 변경은 기존 정보 항목 관리에서 합니다.
- 표시 구성: 표시할 정보, 순서, 형태와 이름 위치, 빈 값, 구분자, 접두·접미 문구를 정합니다. 표시 위치의 색상 제어는 색상 설정으로 옮겼습니다.
- 정보 항목 관리 및 기존 색상 규칙 기능은 유지됩니다.
- 선택 입력: 단일 선택 라디오와 복수 선택 라디오를 구분합니다. 기존 체크박스 방식은 라디오로 표현합니다. 복수 선택은 여러 값을 동시에 켜고 끌 수 있습니다. 참/거짓은 예/아니오 단일 라디오입니다.
- 태그·카테고리는 각각 아래 공통 검색창에서 추가합니다. 위에는 배분된 항목과 선택 값이 표시됩니다. 태그 머리나 카테고리 분류가 추가 자체를 막지 않습니다.
- 고급 설정에서 태그 머리/카테고리 분류, 배분 우선순위, 기본 항목을 지정합니다. 카테고리는 하위 분류도 포함합니다. 여러 규칙에 맞으면 큰 우선순위의 한 항목에 배분합니다. 동률이면 입력 순서, 불일치하면 기본 항목입니다. 기본 항목은 유형마다 하나이며 미지정 시 규칙 없는 항목 또는 첫 항목을 사용합니다.
- 검색어가 있을 때만 드롭다운이 열립니다. 화살표/Enter 선택, Esc와 외부 클릭 닫기를 지원합니다. 선택 후 검색어를 비웁니다. 새 값 생성은 검색 결과 아래에서 시작하며 생성 후 자동 배분합니다.
- Record 카드의 태그·카테고리도 카드 아래 공통 검색창에서 입력합니다. 북마크 태그 자동 등록과 카드 제거 시 정리, 카드 독립 편집 동작을 유지했습니다.

기존 데이터 구조와 데이터베이스 이름을 유지합니다. 기존 태그 머리 한정/우선 설정은 분류 규칙으로 읽고 구성 저장 시 새 규칙으로 보존합니다. 데이터 전체 초기화는 하지 않습니다.
