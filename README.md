# v4.45

압축을 풀고 index.html을 브라우저에서 열어 사용합니다.

## 태그 선택기와 슬라이더

- 선택값에 단계형 슬라이더를 추가했습니다.
- 태그는 공통 검색 외에 드롭다운, 단일·복수 라디오, 순환 버튼, 단계형 슬라이더를 지원합니다.
- 입력 구성에서 정보 유형 ‘태그’와 원하는 입력 방식을 지정하고, ‘선택·상세 설정’에서 선택 가능한 태그를 편집합니다.
- 태그 ID를 저장하며 태그 헤드별·철자순 정렬과 기존 태그색을 유지합니다.
- 선택지에서 제외해도 원본 태그·저장값은 유지합니다. 제외된 기존 값은 표시하고 변경·해제할 수 있습니다.
- 슬라이더는 선택지에 정확히 붙습니다. 미입력 상태에서는 손잡이를 숨기며 조작 전에는 저장값을 만들지 않습니다.
- 방향키, Home, End와 지우기를 지원합니다. 선택지가 하나이면 버튼으로 명시적으로 선택합니다.
- 일반 입력·내부 레코드 카드·입력 미리보기에서 같은 입력기를 사용합니다.
- 복수 저장값이 있으면 단일 선택으로의 변경을 차단합니다.

## 입력 구성 고급 설정

필수 입력과 안내 문구를 유지하며 초기값은 추가하지 않습니다.

- 텍스트·메모·URL의 최소·최대 글자 수.
- 숫자·시간 길이·날짜·시각·날짜+시간의 최소·최대값.
- 숫자·시간 길이의 입력 간격. 시간 길이 제한 단위는 초입니다.
- 다중값·레코드의 최소·최대 선택 개수.
- 라디오 선택지의 가로·세로 배치와 긴 목록 접기.
- 드롭다운 선택지 검색과 슬라이더 눈금 이름 표시.
- 기존 공통 검색의 분류별 배분·우선순위·미분류 수신 설정.
- 공통 검색에서 새 항목 생성 허용.
- 레코드 조회 범위·중복 연결·생성 허용과 유형별 내부 입력 정보 선택. 이름·필수 정보는 유지합니다.
- 입력 묶음의 제목·가로·세로 배치.

제한은 일반 입력과 내부 레코드 카드의 저장 시 검증합니다.

## 표시 구성 고급 설정

- 유형에 맞는 조건을 설정하여 표시 위치를 보이거나 숨깁니다.
- 값 필터와 표시 조건은 별개입니다. 특정 값·태그 헤드·하위 카테고리를 필터링할 수 있습니다.
- 조건에 맞는 전체 값 또는 앞선 위치에서 표시하고 남은 값을 배분할 수 있습니다.
- 최대 표시 개수와 나머지 펼치기.
- 기존 이름 위치·빈 값 대체·구분자·줄바꿈·앞뒤 글자와 직접 지정할 구분자.
- 제목·본문의 URL 정보 연결, 링크 해제, 새 탭 설정.
- 레코드의 요약·상세, 기본 펼침, 표시할 내부 정보. 내부 상세 레이아웃은 해당 레코드의 표시 구성에 따릅니다.
- 묶음 제목·가로·세로 배치·기본 접힘.
- 해당 위치의 색상 구성으로 이동.

## 성별에 따른 레코드 제목 색상

1. 레코드 탭에서 입력·표시·색상 구성을 엽니다.
2. 색상 구성에 규칙을 추가합니다.
3. 기준 정보 ‘성별’, 조건 ‘같음’, 원하는 성별 선택지를 지정합니다.
4. 적용 위치 ‘레코드 이름·제목 공통’, 글자색을 지정합니다.
5. 각 성별 선택지의 규칙을 추가하고 구성 저장을 누릅니다.

북마크의 레코드 표시 항목 → 고급 → 값 표현 → ‘레코드 제목 색상’은 기본적으로 ‘레코드 색상 따르기’입니다. ‘기본 글자색’이나 ‘북마크 색상 구성 사용’으로 바꿀 수 있습니다.

- 레코드 탭의 이름·제목과 북마크 안의 레코드 이름에 같은 규칙을 적용합니다.
- 한 북마크의 여러 레코드는 각각 자신의 값으로 계산합니다.
- 내부 카드에서 성별을 바꾸면 내부 카드 값으로 계산합니다.
- 선택지 ID에 연결하므로 이름 변경 후에도 규칙을 유지합니다.
- 기존 성별 제목 규칙을 공통 제목 대상으로 이어받습니다.

## 호환성 및 검증

4.44의 색상 구성과 기존 입력·표시 기능을 유지합니다. 기존 값 필터·남은 값 배분·제목 URL 연결·레코드 상세 설정을 현재 구성에 맞춰 복원했습니다. 범위·개수 제한과 단계형 슬라이더는 새 기능입니다.

4.41 데이터 로드·저장의 값 유지, 선택지 편집, 태그 정렬, 레코드 연결, 색상 조건과 우선순위, 실제 입력·저장, 설정 취소, 표시 조건·필터·배분, 레코드별 제목 색상, 탭 복제 시 색상 대상 재연결, 실제 드래그, 모바일 가로 넘침을 확인했습니다.
