# Tagmark v4.35

v4.34를 기반으로 입력·표시 구성의 독립 편집, 저장 정보에 따른 색상, 공통 태그·Record 입력기를 추가한 버전입니다.

## 실행과 기존 데이터

압축을 풀고 `v4.35/index.html`을 Chrome 등 브라우저에서 여세요. 별도 설치나 서버가 필요하지 않습니다. 데이터는 기존과 동일하게 브라우저의 로컬 DB에 저장되며 동기화 기능은 없습니다.

기존 4.34에서 사용한 브라우저 환경으로 여세요. 기존 데이터가 나타나지 않으면 4.34의 **DB 관리 → Export**에서 내보낸 v4 Format 1 JSON을 새 버전의 **Import / 전체 교체**로 가져오세요. Import는 현재 DB 전체를 교체합니다. 첨부된 구형 Tagmark 백업 JSON은 별도 형식이므로 직접 가져오기 대상으로 사용하지 마세요.

기존 표시 설정과 저장값은 이어받습니다. 입력 구성은 기존 편집 가능한 항목으로 초기화되며, 공통 입력기로 자동 변경하지 않습니다. 입력 구성만 저장하면 기존 표시 구성은 유지됩니다.

## 설정 열기

북마크 또는 Record 탭의 **더보기 → 입력·표시 구성**을 엽니다. 네 가지 탭이 있습니다.

- **정보 항목**: 공용 항목 생성·이름·유형·선택지·여러 값 허용 등의 설정.
- **입력 구성**: 입력 영역과 항목의 배치·순서·별칭·입력 방식·안내 문구·필수 여부·초기값.
- **표시 구성**: 표시 영역과 항목의 배치·순서·별칭·형식·라벨·접힘·색상.
- **색상 규칙**: 대표 색상의 결정 방식과 적용 범위.

영역과 항목은 ↑ / ↓로 순서를 바꿀 수 있습니다. 배치 해제는 저장값을 삭제하지 않습니다. 입력 항목은 같은 구성에 한 번만 배치하며, 표시는 같은 정보를 여러 위치에서 사용할 수 있습니다. 입력에 배치하지 않은 기존 값은 편집 저장 시 유지됩니다.

구성 변경은 **구성 저장**으로 확정하며 **취소**나 닫기는 변경을 버립니다. **정보 항목의 생성·설정·삭제는 별도 저장 작업**입니다. 이 작업은 구성 취소로 되돌리지 않습니다. **추가 설정 → 고급 필드 설정**에서 기존 표시 조건·프리셋 등 세부 기능에도 접근할 수 있습니다. 이 화면으로 전환하면 현재 구성 초안은 취소됩니다.

## 공통 입력기

입력 영역의 **입력 방식**을 `공통 태그 입력기` 또는 `공통 Record 입력기`로 지정하고 같은 유형의 정보 항목을 배치하세요. 유형이 섞여 있으면 구성을 저장할 수 없습니다.

입력 화면의 대상 버튼으로 저장할 항목을 고릅니다. 검색창은 하나를 공유하지만 항목별 값 목록은 따로 남습니다. 대상을 바꾸면 검색어를 초기화하고 해당 항목의 조회 범위를 적용합니다.

태그는 조회할 머리, 새 태그의 기본 머리, 생성 허용 여부를 설정합니다. Record는 조회할 탭, 새 카드 생성 허용 여부, 동일 원본의 복수 카드 허용 여부를 설정합니다. 기존 Record를 검색해 추가하거나 북마크 전용 카드를 만들 수 있습니다.

Record 카드의 편집은 해당 Record 유형의 입력 구성을 사용합니다. 카드 수정은 원본을 자동 변경하지 않습니다. **전역 Record로 즉시 등록**은 기존과 동일하게 별도 저장 작업입니다. 태그 머리 우선등록 기능도 유지됩니다.

## 표시와 색상

색상 결정 방식은 기본 화면색, 고정색, 조건별입니다. 조건은 `같음 / 포함 / 비어 있음 / 값 있음`을 지원하며, 위에서부터 첫 번째로 일치하는 규칙을 적용합니다. 불일치 시 사용할 기본색을 지정하거나 화면색으로 되돌릴 수 있습니다.

대표 색상의 적용 범위는 이름·제목, 정보값, 태그·칩, 정보 이름, 카드 테두리, 옅은 카드 배경입니다. 라벨은 기본 중립색으로 유지합니다. 밝은 색은 읽기 편한 진한 글자색과 옅은 배경색으로 변환됩니다.

각 표시 위치에서는 전체 설정, 기본 화면색, Record 색상 따르기, 항목 자체 색상, 별도 고정색, 별도 조건 규칙을 선택할 수 있습니다. 태그 자체 색상을 선택하면 원래 태그색을 유지합니다. 표시 색상 변경은 원본 태그의 색상 정보를 수정하지 않습니다.

북마크 내부 Record 카드는 자신의 저장값으로 색상을 계산합니다. 카드의 성별 등을 바꾸면 그 카드의 색상만 바뀝니다. 중첩된 Record는 자신의 색상을 사용합니다.

## 이번 구현 범위

개별 입력 및 공통 태그·Record 입력, 단일 조건의 순차 색상 규칙, 독립 입력·표시 배치를 제공합니다. 복합 AND/OR 조건과 태그 머리에 따른 공통 입력 대상 자동 판별은 포함하지 않습니다. 선택지는 기존 저장 문자열 형식을 유지하며, 값이 저장된 선택 항목의 선택지 변경 제한도 유지합니다.

## 검증

Chrome 엔진에서 구성 취소, 입력에서 숨긴 값 보존, 표시·입력의 독립 변경, 동일 정보의 복수 표시, 태그 조회 범위 및 항목별 저장, Record 중복 설정, 카드 독립 저장·색상, 숨긴 Record 항목의 필수 검사, 재실행 후 설정·값 유지, DB 구조 검증을 확인했습니다. 데스크톱과 좁은 화면에서 설정 화면도 확인했습니다.
