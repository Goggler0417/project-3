# v4.44

압축을 풀고 index.html을 브라우저에서 열어 사용합니다.

## 색상 구성

- 입력 구성의 정보 항목을 기준으로, 표시 구성의 실제 위치에 색상을 적용합니다.
- 카드 배경·테두리·강조선과 표시 항목별 기본 스타일을 설정할 수 있습니다.
- 텍스트, 메모·설명, URL, 숫자, 시간 길이, 날짜, 시각, 날짜+시간, 예/아니오, 선택값, 태그, 카테고리, 레코드를 지원합니다.
- 조건 규칙은 추가·수정·복제·삭제·비활성화·드래그 정렬을 지원합니다. 정렬 손잡이에 초점을 두고 위·아래 방향키로도 순서를 변경할 수 있습니다.
- 위 규칙이 같은 위치의 같은 색상 속성에 우선합니다. 서로 다른 속성은 함께 적용됩니다.
- 태그·다중 선택 칩은 모든 값 또는 조건에 맞는 값만 색칠할 수 있습니다.
- 기존 태그 헤드색·개별 태그색은 지정한 속성만 덮어씁니다.
- 미리보기 항목을 선택하고 실제 표시 구성에 적용된 규칙을 확인할 수 있습니다.
- 정보 유형 변경, 표시 위치 삭제·숨김, 선택지·분류 삭제로 연결이 유효하지 않은 규칙은 재지정 안내를 표시하고 적용하지 않습니다.
- 선택지는 ID로 연결합니다. 이름 변경 시 연결을 유지하고 삭제 시 지정한 대체 선택지로 연결합니다.
- 정보 삭제 확인에는 관련 색상 규칙 삭제 안내를 포함합니다.
- 기존 전체·표시 위치별 색상 규칙을 새 색상 구성으로 이전합니다. 기존 성별 조건은 호환 조건으로 유지합니다.
- 구성 저장으로 확정합니다. 취소하면 편집 내용을 반영하지 않습니다.

## 양식 통일

- 입력 구성의 레코드 카드 미리보기와 실제 카드가 같은 이름·검색 통합 입력기를 사용합니다.
- 레코드 카드 미리보기의 내부 태그·카테고리 검색기도 해당 정보 위치에 표시합니다.
- 시간 길이는 일반 입력·레코드 카드·색상 조건에서 동일한 시·분·초 입력기를 사용합니다. 0도 정상적인 입력값입니다.
- 선택하지 않은 상태는 ‘선택 안 함’, 태그 헤드가 없는 상태는 ‘미지정’으로 통일했습니다.
- 태그 그룹·태그 머리·Head 표시를 ‘태그 헤드’로 통일했습니다.
- 기본 종류명과 페이지 설정 등 기본 화면 문구를 한국어로 통일했습니다. 기존 데이터에 저장된 사용자 이름은 유지합니다.
- 선택 가능한 설정이 하나인 경우 고정된 문구로 표시합니다. 실제 데이터 선택은 사용자가 명시적으로 입력합니다.

## 검증

4.41 데이터 로드·저장 시 북마크·레코드 값 유지, 입력·표시 구성의 기존 기능, 정보 삭제 취소, 선택지 이름 변경·삭제 대체, 태그 정렬, 레코드 연결, 정보 유형별 색상 조건, 속성별 우선순위, 실제 카드 색상, 저장 후 재열기, 실제 드래그, 모바일 가로 넘침을 확인했습니다.

첫 구현 범위는 규칙 하나당 조건 하나와 적용 위치 하나입니다. 여러 조건의 AND/OR 조합과 레코드 내부 정보를 탐색하는 조건은 포함하지 않습니다.
