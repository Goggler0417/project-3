# v4.48

압축을 풀고 index.html을 브라우저에서 엽니다. v4.47의 기능과 데이터 형식을 유지합니다.

## 수정 사항

1. 슬라이더 자동 모드에서 선택지가 7개를 넘으면 가운데 이름이 사라지던 문제를 수정했습니다. 자동 모드는 모든 선택지 이름을 표시합니다. 글자색과 태그 칩 대비도 유지합니다.
2. 폴더 요약은 v4.47의 배치·순서·구분 기호·두 값과 나머지 개수 표시를 유지합니다. 태그의 글자색과 배경색만 태그 탭과 동일하게 적용합니다.
3. 레코드 성별·제목 색상·색상 구성은 v4.47 방식으로 유지합니다. 이번 버전의 성별 자동 색상 및 내부 레코드 색상 조건 추가는 되돌렸습니다.
4. 태그 탭과 폴더 요약의 태그 헤드 선택을 검색 가능한 다중 선택기로 바꿨습니다. 전체 표시 / 직접 선택, 전체 선택 / 전체 해제, 선택 칩 제거, 헤드 없는 태그를 지원합니다.
5. 일괄 수정에 묶음 규칙으로 자동 배분하는 방식을 추가했습니다. 입력한 항목 ID가 달라도 태그 헤드와 상위 카테고리 규칙으로 받을 항목을 결정합니다. 레코드의 기본 자동 입력에서도 유형이 호환되고 이름이 일치하는 유일한 항목을 연결할 수 있습니다.

6. 레코드는 별도 화살표 없이 제목 영역을 클릭하거나 키보드로 접고 펼칩니다. 성별 색상 처리는 v4.47 그대로입니다.
7. +만 표시되던 버튼에 추가 대상을 명시했습니다. 예: 북마크+, 레코드+, 태그 헤드+, 하위 카테고리+, 정보+.

## 사용법

### 태그 헤드 선택

태그 탭의 ‘탭 설정’에서 표시할 헤드를 선택합니다. 북마크 탭의 ‘탭 설정’에서는 폴더 요약 정보와 요약에 표시할 헤드를 설정합니다. 태그가 포함된 정보 항목을 요약 정보로 선택해야 태그 칩이 나타납니다.

- 전체 표시: 새로 만든 헤드도 포함합니다.
- 직접 선택: 체크한 헤드만 표시합니다. 전체 해제하면 아무것도 표시하지 않습니다.
- 헤드 없는 태그: 별도로 켜고 끌 수 있습니다.

### 일괄 수정 자동 배분

입력 구성에서 태그·카테고리 항목을 묶음에 넣고 각 항목의 받을 분류와 우선순위를 지정합니다. 일괄 수정에서 묶음 안의 태그 또는 카테고리 항목을 고르면 ‘적용 방식’이 나타납니다.

- 선택 항목에 적용: 지정한 정보 항목에 값을 적용합니다.
- 묶음 규칙으로 자동 배분: 값의 분류를 보고 묶음 안에서 받을 항목을 결정합니다. 이름이나 ID로 검색하며 여러 ID는 쉼표·공백으로 구분합니다.

배분 순서는 일치하는 태그 헤드 / 가까운 상위 카테고리 → 높은 우선순위 → 구성 순서 → 기본 수신 항목입니다. 수신 항목이 결정되지 않으면 직접 선택해야 적용할 수 있습니다. 명시적으로 설정한 묶음 검색 범위는 유지합니다.

- 설정·전체 교체: 값이 배분된 항목만 교체합니다. 다른 항목은 유지합니다.
- 추가: 해당 수신 항목에 추가하며 같은 묶음의 중복값을 정리합니다.
- 제거: 입력 분류가 바뀌었어도 묶음 안에서 값이 실제로 저장된 항목을 찾아 제거합니다.
- 비우기: 현재 선택한 정보 항목만 비웁니다.

변경 미리보기에서 수신 항목과 변경 전후 값을 확인합니다. 수신 항목의 필수 여부·단일 선택·허용 선택지·개수 제한을 검사하며 오류가 있으면 적용하지 않습니다. 묶음 밖으로 자동 이동하지 않습니다.

## 검증

레코드 표시·성별·색상 구성 함수와 출력이 v4.47과 일치하는지 비교했습니다. 폴더 요약도 색상용 내부 요소를 제외한 마크업과 표시 문구가 v4.47과 일치하는지 비교했습니다. 폴더 태그의 실제 글자색·배경색이 태그 탭과 동일한지 확인했습니다.

슬라이더 가독성, 기존 일괄 수정과 묶음 자동 배분, 저장값 보존 검사도 통과했습니다.

추가 확인: 실제 입력 구성을 통해 자동 모드 선택지 10개의 이름과 가운데 선택값 반영을 확인했습니다. 레코드 제목 클릭·Enter 동작과 화살표 숨김, +만 있는 버튼의 제거를 확인했습니다.
