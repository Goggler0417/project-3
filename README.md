# Tagmark v4.37

v4.36 기반으로 설정 화면을 단순화하고 태그 검색을 드롭다운으로 변경했습니다.

## 실행

압축을 풀고 `v4.37/index.html`을 브라우저에서 여세요. 데이터는 브라우저의 로컬 DB에 저장됩니다. 기존 데이터가 보이지 않으면 이전 버전의 **DB 관리 → Export**로 내보낸 v4 Format 1 JSON을 새 버전에서 가져오세요. Import는 현재 DB 전체를 교체합니다.

## 간편 설정

북마크 또는 Record 탭의 **더보기 → 입력·표시 구성**에서 항목별 한 줄 설정이 열립니다.

- 정보 항목의 표시 이름, 입력 여부, 표시 형식을 한 줄에서 변경합니다.
- 태그의 빠른 설정에서 머리·전체/한정/우선등록·생성 허용을 지정합니다.
- Record의 빠른 설정에서 조회할 탭을 지정합니다.
- `설정` 버튼은 항목별 별칭·입력 방식·필수값·초기값·라벨 등의 상세 설정을 엽니다.
- 태그와 Record 입력을 각각 항목별 또는 공통 검색창으로 변경합니다. 항목별 값과 조회 범위는 유지됩니다.
- 색상은 기본 / 직접 지정 / 정보에 따라 중에서 선택합니다. 정보에 따라를 선택하면 정보 항목별 조건값과 색상을 설정합니다. 기존 복합적인 순차 규칙은 상세 규칙에서 계속 편집할 수 있습니다.
- 미리보기에서 현재 구성의 표시 결과를 확인합니다.

입력 체크와 표시 형식은 독립적입니다. 입력을 해제하거나 표시를 숨겨도 저장값을 삭제하지 않습니다. 기존 반복 표시와 영역 설정도 유지합니다. ↑ / ↓는 입력·표시 영역과 그 안의 항목 순서를 함께 정리하며, 영역 묶음은 유지합니다. 서로 다른 배치나 순서가 필요하면 **상세 구성**에서 각각 편집하세요.

**상세 구성**의 `간편 구성` 버튼으로 돌아올 수 있습니다. 두 화면은 같은 초안을 사용합니다. 변경은 하단 **저장**으로 확정하고, **취소**는 초안을 버립니다. 항목별 상세 설정의 변경도 최종 구성 저장 전에만 적용된 초안입니다.

공용 정보 항목의 생성·수정·삭제와 전역 Record 즉시 등록은 별도 저장 작업입니다. 구성 취소는 이 별도 작업을 되돌리지 않습니다. 새 정보 항목을 간편 화면에서 만들면 입력·표시 초안에도 자동 배치됩니다.

## 태그 검색

평상시에는 검색창과 이미 추가한 태그만 보입니다. 전체 태그 목록과 머리별 빠른 등록 목록은 펼쳐두지 않습니다.

- 검색어를 입력하면 검색창 아래 드롭다운에 결과가 나타납니다.
- 선택하면 해당 항목에 추가하고 검색어와 드롭다운을 비웁니다.
- 검색어 삭제, 바깥 클릭, Esc는 드롭다운을 닫습니다.
- ↑ / ↓로 결과를 고르고 Enter로 추가합니다.
- 드롭다운 마지막의 `＋ “검색어” 태그 만들기`로 생성 창을 엽니다. 검색어와 지정된 기본 머리가 미리 적용됩니다.

개별 입력기, 공통 입력기, Record 카드 안의 개별·공통 태그 입력기에 적용됩니다. 공통 입력기의 항목 전환 시 검색어는 초기화됩니다.

**머리 한정**은 해당 머리의 태그만 검색·추가·생성합니다. **머리 우선등록**은 지정 머리의 결과를 앞에 정렬하고 전체 검색도 허용합니다. Record에서 불러온 태그의 우선등록과 카드 삭제 시 자동 추가 태그 정리 규칙은 유지됩니다. 범위 변경 전 저장한 태그도 유지합니다.

## 검증

Chrome 엔진에서 간편·상세 전환 시 초안 유지, 저장·취소, 숨긴 값 보존, 독립 입력·표시 구성, 항목별 태그 저장, 조회 범위와 Record 카드 독립 저장, 조건별 색상, 재실행 후 DB 구조를 확인했습니다. 실제 화면 조작으로 태그 키보드 선택·Esc·바깥 클릭·검색어 기반 생성과 Record 카드 개별·공통 드롭다운을 확인했습니다. 데스크톱·좁은 화면 설정 배치도 확인했습니다.
