# v4.46

압축을 풀고 index.html을 브라우저에서 열어 사용합니다. v4.45의 기능을 유지하면서 태그 선택지 순서와 슬라이더 배치를 수정했습니다.

## 태그 선택지 순서

입력 구성 → 태그 정보의 고급 설정 → 선택·상세 설정 → 선택 가능한 태그 편집.

- 선택된 태그 목록에서 ≡를 끌면 ‘직접 정렬’로 전환됩니다.
- 순서 손잡이에 초점을 두고 위·아래 방향키로도 이동할 수 있습니다.
- 긴 선택 목록은 드래그 중 가장자리에서 자동으로 스크롤합니다.
- ‘태그 헤드·철자순’을 선택하면 자동 정렬로 돌아갑니다.
- 적용 → 바깥 구성 저장으로 확정합니다. 취소하면 기존 순서를 유지합니다.
- 직접 정렬한 순서는 해당 입력기의 선택지에 적용합니다. 태그 탭·카드에서의 태그 헤드별·철자순 정렬은 유지합니다.
- 순서를 바꿔도 기존 선택값은 태그 ID로 유지합니다.

## 슬라이더 배치

- 현재 값과 지우기를 위에, 슬라이더와 선택지 칸을 아래에 배치했습니다.
- 손잡이·눈금·선택지 칸의 중심을 같은 간격에 맞췄습니다.
- 선택지 칸을 클릭해도 선택할 수 있습니다.
- 긴 목록은 슬라이더 영역 안에서만 가로로 스크롤합니다.
- 키보드로 선택하거나 기존 항목을 열었을 때 선택된 칸이 보이도록 이동합니다.
- 일반 선택값·태그·레코드 내부·미리보기에서 같은 양식을 사용합니다.
- 미입력 상태와 단일 선택지의 명시적 선택 동작을 유지합니다.

## 값 앞·뒤 표시 사용법

표시 구성 → 해당 표시 항목의 ‘고급’을 펼쳐 설정합니다.

| 설정 | 동작 | 예 |
| --- | --- | --- |
| 항목 이름 위치: 숨김 | 정보 이름을 숨깁니다 | 120 |
| 항목 이름 위치: 값 위 | 이름을 값 위에 둡니다 | 페이지 수 / 아래 줄 120 |
| 항목 이름 위치: 값 앞 | 이름을 값 앞에 둡니다 | 페이지 수 120 |
| 항목 이름 위치: 값 뒤 | 이름을 값 뒤에 둡니다 | 120 페이지 수 |
| 값 앞에 붙일 문구 | 값 앞에 고정 문구를 붙입니다 | ‘약 ’ → 약 120 |
| 값 뒤에 붙일 문구 | 값 뒤에 고정 문구를 붙입니다 | ‘ 페이지’ → 120 페이지 |

고정 문구는 표시 방식을 ‘본문’으로 지정하면 설정할 수 있습니다. 띄어쓰기를 포함해 입력한 문구 그대로 표시합니다. 이름을 숨기고 앞 문구 ‘약 ’와 뒤 문구 ‘ 페이지’를 사용하면 ‘약 120 페이지’가 됩니다.

‘표시 조건’은 해당 항목 전체를 보이거나 숨깁니다. ‘값 필터’는 여러 저장값 중 표시할 값만 고릅니다. ‘값 배분: 남은 값’은 앞선 표시 위치에서 사용하고 남은 값을 보여줍니다. 아래 표시 화면 미리보기에서 확인하고 구성 저장으로 확정합니다.

## 검증

실제 포인터 드래그, 순서 저장·재열기·취소, 기존 태그 선택값 유지, 데스크톱·모바일의 손잡이와 눈금 중심 정렬, 슬라이더 내부 가로 스크롤, 선택지 칸 클릭, 값 앞뒤 문구와 공백 보존, 항목 이름의 값 뒤 배치, 기존 데이터 호환·입력·레코드·색상 기능을 확인했습니다.
