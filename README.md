# Tagmark v4.33

북마크, Record, 태그 등을 한 페이지에서 관리하는 단일 HTML 앱입니다.

## 실행

1. 이 압축 파일을 풉니다.
2. `v4.33/index.html`을 브라우저에서 엽니다.
3. 데이터는 브라우저의 로컬 데이터베이스에 저장됩니다. 다른 브라우저나 기기에서 같은 파일을 열어도 데이터가 자동으로 옮겨지지는 않습니다.

## 필드와 하위 영역 설정

- 북마크 또는 Record 탭에서 **필드 편집**을 엽니다.
- 상단 **＋**는 새 필드를 만들고, 각 필드 아래 **＋ 하위 영역**은 해당 필드에 독립된 정보 항목을 추가합니다.
- 같은 저장값을 여러 곳에 표시하려는 경우에만 **기존 정보 연결**을 선택합니다. 이때 연결된 곳들은 하나의 정보 항목과 저장값을 공유합니다.
- 하위 영역 행의 이름은 해당 위치의 표시 이름입니다. 공용 정보 항목 자체의 이름은 **고급 → 정보 항목 설정**에서 수정합니다.
- 필드 머리글의 **삭제**는 해당 표시 영역을 제거합니다. 하위 영역만 제거하려면 그 행의 **고급 → 이 하위 영역 삭제**를 사용합니다. 저장된 값을 가진 공용 정보 항목은 **전체 정보 항목**에 남을 수 있습니다.
- 수정한 설정은 화면 아래 **저장**으로 확정합니다.

## 레코드 입력기

- 새 필드를 만들 때 **정보 종류 → Record**를 선택하면 레코드 입력기가 적용됩니다. 생성 창에서 검색할 Record 탭을 고를 수 있습니다.
- 기존 Record 필드는 해당 행의 **고급 → Record 입력 설정**에서 검색할 탭을 지정합니다. 이 범위는 개별 필드의 설정입니다.
- 북마크 편집 화면에서는 레코드 카드가 0개로 시작합니다. **＋ 레코드 추가**를 누를 때마다 카드가 한 개씩 생깁니다.
- 카드를 만든 뒤 기존 Record를 검색해 불러오거나 북마크 전용으로 입력할 수 있습니다. 카드에서 수정한 정보는 원본 Record를 변경하지 않습니다.
- 원본 태그를 불러올 때 태그 머리 우선등록 규칙을 적용합니다. 북마크 목록의 레코드 세부 정보는 기본으로 접혀 있습니다.

## 백업과 복원

왼쪽 메뉴의 **DB 관리**에서 JSON 백업을 다운로드하고 가져올 수 있습니다. 브라우저 데이터 삭제나 다른 기기로 이동하기 전에는 백업 파일을 별도로 보관하세요. 가져오기는 v4 데이터베이스 형식의 JSON을 대상으로 합니다.
