# v4.41

압축을 풀고 index.html을 브라우저에서 엽니다. 기존 데이터를 먼저 JSON으로 내보낸 뒤 새 파일을 여세요. 파일 주소가 달라져 기존 데이터가 보이지 않으면 JSON을 가져오세요.

## 구성 화면

입력·표시 구성은 4.36 이전의 간결한 항목 행 형태입니다. 기본 한 줄에는 항목 이름, 정보 유형, 입력/표시 방식과 작은 아이콘만 있습니다. 화살표로 펼치면 고급 설정 한 줄만 추가됩니다. 많은 옵션은 툴바 안에서 가로 스크롤합니다.

별도 영역 제목 줄과 매 영역의 기존 정보 추가 줄은 없습니다. 영역 이름·가로 배치·표시 영역 옵션은 첫 항목의 고급 줄에 있습니다. 정보 유형 변경은 기존 정보 항목 관리에서 합니다.

- ≡: 기존 드래그&드롭으로 순서 변경 (이동 미리보기·파란 배치선·자동 스크롤)
- ×: 구성에서 제거 (저장된 데이터는 유지)
- 행의 ＋: 해당 영역에 기존 정보 추가
- 구성 탭 오른쪽 ＋: 새 영역 생성

항목이 하나면 영역과 항목의 순서/제거 기능은 하나로 합쳤습니다. 복수 항목 영역은 항목 드래그 핸들과 첫 행의 영역 전체 드래그 핸들을 구분합니다. ×는 각 항목 제거, ⋯는 영역 전체 제거입니다. 대상이 다른 기능만 구분합니다. 빈 영역도 한 줄이며 ＋로 정보를 넣습니다.

입력 구성은 입력할 정보·방식을, 표시 구성은 표시할 정보·순서·형태를 정합니다. 색상 설정과 정보 항목 관리는 분리되어 있습니다. 기본 설정 외의 안내 문구·초기값·필수 여부·분류 규칙·Record 조회 범위 등은 고급 줄에서 정합니다.

입력 미리보기는 입력 그룹·방식·저장값/초기값·Record 카드와 태그/카테고리 공통 추가창을 보여줍니다. 구성 초안 변경을 즉시 반영하며 읽기 전용입니다. 표시 미리보기는 실제 카드 표시 형태입니다.

## 입력 동작

선택 입력은 단일 선택 라디오와 복수 선택 라디오를 구분합니다. 기존 체크박스 방식은 원형 선택 입력으로 표현하며 복수 선택은 각 값을 독립적으로 켜고 끕니다. 참/거짓은 예/아니오 단일 라디오입니다.

태그·카테고리는 입력 화면 아래 별도 공통 검색창에서 자유롭게 추가합니다. 위에는 항목별 배분된 값이 표시됩니다. 고급 설정의 태그 머리/카테고리 분류 규칙으로 배분하며, 카테고리는 하위 분류도 포함합니다. 여러 규칙에 맞으면 큰 우선순위의 한 항목, 동률이면 입력 순서, 불일치면 해당 유형의 기본 항목으로 배분합니다. 기본 항목은 유형마다 하나이며 미지정 시 규칙 없는 항목 또는 첫 항목을 사용합니다.

검색어가 있을 때만 드롭다운이 열립니다. 화살표/Enter 선택, Esc·외부 클릭 닫기와 선택 후 검색어 비우기를 지원합니다. 검색 결과의 새 값 생성 기능은 검색어를 미리 채우고 생성 후 자동 배분합니다.

Record 카드에서도 태그·카테고리 공통 추가창을 사용합니다. 카드 독립 편집, 북마크 태그 자동 등록과 카드 제거 시 정리 동작을 유지합니다. 기존 색상 규칙, 데이터 구조와 데이터베이스 이름도 유지합니다.

## v4.41
4.40의 화면 구성과 입력·표시 미리보기 및 데이터 기능은 유지하고 순서 변경 조작만 복원했습니다. 입력·표시 영역 이동, 영역 안/영역 간 항목 이동, 색상 규칙 순서는 드래그&드롭으로 변경합니다. 원래 포인터 처리, 이동 미리보기, 배치 위치 표시와 자동 스크롤을 재사용합니다. 새 입력 구성의 초안에 연결하여 취소 시 원본에 반영되지 않고 구성 저장으로 확정됩니다. 잘못된 유형의 입력 영역에는 항목을 옮길 수 없습니다. Esc나 포인터 취소로 드래그를 취소할 수 있습니다.
