# v4.43

v4.42를 기반으로 요청한 입력 화면 개선을 반영했습니다.
압축을 풀고 index.html을 실행하세요. 기존 전체 DB 백업 형식과 데이터베이스 이름은 유지했습니다.

- ‘입력 힌트’를 기존 명칭 ‘안내 문구’로 되돌렸습니다.
- 태그·카테고리 공통 검색기를 각 정보 항목의 입력 위치에 배치했습니다. 공통 배분 규칙은 유지됩니다.
- 입력 구성의 각 항목에 명시적인 ‘수정’·‘삭제’ 버튼을 추가했습니다. 삭제 확인과 저장값 보호는 유지됩니다.
- 레코드 카드에서 이름 입력과 기존 레코드 검색을 한 칸으로 통합했습니다. 검색 결과를 선택해 원본을 연결하거나, 새 이름으로 입력해 별도 모달 없이 카드 내용을 작성할 수 있습니다.
- 선택한 태그는 태그 머리별로 묶어서 표시하며, 같은 머리 안에서는 이름순으로 정렬합니다. 머리 간 순서는 설정된 머리 순서를 따르고, 미지정 머리는 마지막에 표시합니다.

Chromium에서 정보 수정, 검색기 위치, 태그 정렬, 레코드 이름·검색 통합, 원본 연결, 데이터 유효성 및 이전 버전 데이터 유지와 기존 구성 동작을 확인했습니다.
