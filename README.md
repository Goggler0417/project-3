# Tagmark v4.28

## 핵심 변경

- 표시 구성의 기본 화면을 **정보 종류 + 표시 방식** 중심으로 단순화했습니다.
- 사용자에게 보이는 정보 종류를 `Text / Number / Date & Time / Boolean / Choice / Tag / Record / Category`로 정리하고 `Relation` 같은 내부 용어는 기본 UI에서 숨겼습니다.
- 한 줄/여러 줄/URL, 숫자/시간 길이, 날짜/날짜+시간, Choice 입력 방식은 해당 정보 종류의 **입력 세부**에서만 나타납니다.
- 영역 배치는 정보가 2개 이상 있는 영역에서만 표시됩니다.
- 고급 설정을 `입력 세부 / Record 입력 / 영역 배치 / 항목 이름 표시 / 표시 조건 / 표시 꾸미기`로 접어 두어 필요한 설정만 열 수 있게 했습니다.
- Record 입력은 기본적으로 **Record 유형 + 입력 모양**만 고르면 되며, 나머지는 자동 설정됩니다.
- Record 입력 모양은 `일반 검색 / v1 Profile 박스` 두 가지입니다.
- Bookmark 자동 입력은 `기본(같은 정보 항목만) / 사용 안 함 / 사용자 지정`으로 단순화했습니다. 세부 매핑, 새 Record 등록 항목, 검색 보조 정보, v1 슬롯 직접 연결은 `사용자 지정` 안에 유지됩니다.
- 기존 Record 박스, Record 검색/즉시 등록, 선택 복사/붙여넣기, 정보 다시 불러오기, 자동 입력 출처 기록은 유지됩니다.

## 테스트 파일

`test.html`은 v4.28 전용 IndexedDB `tagmark-v428-test`를 사용하여 일반 `index.html` 데이터와 분리됩니다.

권장 테스트 순서:

1. `test.html`을 열고 **북마크 → 표시 구성**을 열어 기본 행이 `정보 항목 / 정보 종류 / 표시` 중심으로 단순해졌는지 확인합니다.
2. Text, Number, Choice 항목의 **고급 → 입력 세부**를 열어 해당 종류에 필요한 선택지만 나타나는지 확인합니다.
3. `관련 Record → 고급 → Record 입력 설정`에서 기본 화면에 `Record 유형 / 입력 모양 / Bookmark 자동 입력`만 먼저 보이는지 확인합니다.
4. `사용자 지정`을 열어 v1 슬롯, 새 Record 등록 정보, 검색 보조 정보, 직접 자동 연결을 확인합니다.
5. `테스트 북마크 C`를 수정해 Alice/Bob이 **v1 Profile 박스**로 표시되고 검색, 새 Record 등록, 선택 복사/붙여넣기, 정보 다시 불러오기가 작동하는지 확인합니다.
6. 390px 정도의 모바일 폭에서도 표시 구성과 Record 박스가 가로로 넘치지 않는지 확인합니다.
