# v4.49

압축을 풀고 index.html을 브라우저에서 엽니다. v4.48을 기준으로 화면과 조작 체계를 정리한 첫 번째 버전입니다.

## 기본 화면

- 검색창은 한 줄로 두고 정렬·사용 여부·그리드/목록 등은 ‘보기’에 모았습니다.
- 북마크 검색 범위와 빠른 카테고리 필터는 ‘필터’에서 선택합니다. 기존 세부 필터도 이 메뉴에서 엽니다.
- 북마크·레코드 탭의 ‘구성’에서 입력 구성 / 표시 구성 / 색상 구성 / 탭 설정을 엽니다. 태그·카테고리 탭도 같은 위치에서 탭 설정을 엽니다.
- 폴더 관리, 그룹 변경 등 나머지 작업은 ‘더보기’에 있습니다.
- 태그 등록의 대상 헤드는 ‘추가할 태그 헤드’에서 펼쳐 선택합니다. 선택된 헤드 이름은 접힌 상태에서도 확인할 수 있습니다.

## 선택 모드

네 탭 모두 선택 개수와 해당 작업 버튼, 더보기, 선택 종료를 같은 방식으로 표시합니다. 선택 모드에서는 일반 작업 줄을 숨깁니다.

전체 선택·선택 해제·복사/붙여넣기·삭제 등은 선택 전용 ‘더보기’에 모았습니다. 북마크·레코드는 선택 0개에서도 더보기의 ‘ID로 대상 찾기’를 사용할 수 있습니다. 적용할 대상이 필요한 동작은 0개에서 비활성화합니다.

## 입력·표시 구성

기본 행은 드래그 손잡이, 이름, 유형, 입력/표시 방식, 세부 설정으로 구성합니다.

- ‘세부 설정’을 누르면 필수 입력·안내 문구, 선택지 편집·검색/조회 범위 등 필요한 설정을 먼저 보여줍니다.
- 값 제한, 세부 표현, 조건, 배분 우선순위 등은 ‘고급 옵션’을 펼쳐 사용합니다.
- 삭제·정보 정의 수정·표시 숨김은 해당 항목의 세부 설정 하단으로 옮겼습니다.
- 묶음의 입력 방식은 바로 선택하고, 배치·제목 표시·해제 등은 ‘묶음 세부 설정’에 모았습니다.
- 색상 구성의 기본 스타일은 ‘기본 색상 설정’ 안에 접어두었습니다. 조건 규칙과 미리보기는 계속 사용할 수 있습니다.
- 드래그 순서 변경과 구성 미리보기를 유지합니다. 동일 구성에서 옵션을 바꾸며 화면을 다시 그릴 때 펼친 설정과 스크롤 위치를 유지합니다.

## 공통 양식

일반 버튼과 한 줄 입력은 높이 36px, 조밀한 보조 버튼은 30px를 기준으로 맞췄습니다. 칩과 보조 설명의 글자 크기, 테두리와 모서리, 주요 실행·일반·삭제 버튼의 표현을 정리했습니다. 추가 동작은 정보+, 묶음+, 규칙+처럼 대상을 표시합니다.

모달은 작은 편집 440px, 일반 편집 680px, 구성·일괄 수정 960px를 기준으로 통일했습니다. 제목과 하단 동작은 고정하고 내용만 스크롤합니다. 모바일에서는 화면 너비에 맞춥니다.

선택지·범위 등 하위 편집을 열면 기존 모달을 값을 유지한 채 숨깁니다. 화면에는 편집 모달 하나만 나타나며 ‘뒤로’로 돌아옵니다. 키보드 Tab은 현재 편집 안에서 이동하며, Escape는 열린 메뉴 → 하위 편집 → 기본 편집 순서로 닫습니다.

## 유지한 동작

슬라이더 자동 모드의 모든 선택지 이름, 레코드 제목 클릭 접기/펼치기, v4.47 기준의 레코드 성별·색상 처리, 기존 폴더 요약 방식과 태그 색상은 유지합니다. 일괄 수정의 입력기 재사용·ID 조회·제한 검사·자동 배분과 변경 미리보기도 유지합니다.

## 검증

브라우저에서 실제 드래그 후 구성 저장, 하위 편집 복귀 시 작성값 유지, 네 탭의 선택/전체 선택/종료, 색상 옵션 접근, Escape 취소, 고정 하단 버튼, 모바일 네 탭을 확인했습니다.

숫자 0·아니오·슬라이더·태그 추가/제거·레코드 연결의 일괄 저장, 제한 오류 차단, 취소 시 값 유지, 묶음 자동 배분과 수신 항목 제한도 확인했습니다. 선택지 10개의 자동 표시와 가운데 선택 동작, v4.48 데이터 보존과 재시작 후 저장값 보존 검사도 통과했습니다.
